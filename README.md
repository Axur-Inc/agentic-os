# Agentic OS

Two pieces published together, plus a starter kit to try the architecture yourself.

---

## Read this first

### [Restructuring Knowledge Work for Human-Agent Teams](manifesto.md)

The argument piece (~1,450 words). The thesis: the substrate underneath the agents is the durable asset, not the agents themselves. Starts with the bet, shows what happened when we ran it, makes the case for why most agentic transformations will stall at the tool layer. Written to circulate on its own. **Start here.**

### [An Agentic Operating System: Seven Weeks of Practice](field-report.md)

The companion handbook (~6,200 words). Full architecture, six principles, seven conventions, six concrete examples of what non-engineers built and how the pattern spread across functions, the live data (MCP) layer, everything that broke, the token economy, what is still open, and a practical guide for replicating this at your own company.

The manifesto makes the argument. The field report is the receipt.

---

## Try it yourself

The **starter kit** is a working seed of the architecture — a minimal, opinionated, tool-agnostic file structure you can fork and populate with your own context.

Fork it, open it in any agentic tool, and say **set me up.** The agent runs a short onboarding interview and generates your personal context files. From there, populate the knowledge base with what your company knows and start using it for real work.

> Starter kit repository: [https://github.com/Axur-Inc/agentic-os/tree/main/starter-kit](https://github.com/Axur-Inc/agentic-os/tree/main/starter-kit)

The starter kit works with Claude Code, Cowork, Cursor, GitHub Copilot, OpenCode, or anything else that reads files and follows instructions.
